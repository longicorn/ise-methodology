# ISE Methodology

このリポジトリでは、AI時代のソフトウェア開発について、**Intent-Synchronized Engineering（ISE）**と**Lane Model**を中心に筆者の考えをまとめています。AI時代になり、これまでの考え方や経験がそのままでは通用しない場面が増えてきました。それをきっかけに、AI時代に生じた課題だけでなく、それ以前から開発に存在していた綻びもあわせて見直し、筆者なりに考え直した結果としてたどり着いたのがISEです。

ISEは、意図と、それを表す成果物やソフトウェアとの整合を保つ方法を考える枠組みです。Lane Modelは、Intent、仕様、コード、観測された事実などの状態を結ぶ開発の流れを捉えます。人間やAIが開発にどう関わるかを含め、開発作業を考えるための視点を提示します。

「Engineering」という名称は、この取り組みを表す便宜的な呼び名です。完成された工学体系や確立した方法論を標榜するものではありません。筆者が学んできたソフトウェアエンジニアリングから理解しやすく有用だと考えた要素を取り出し、適用できる部分に応用しながら、経験や考察をもとに整理を続けています。

このリポジトリには**Intent Guidance Engineering（IGE）**と**Orthogonal Dual-Framework（ODF）**についての初期的な考察も含まれます。これらはまだ構想段階であり、ISEやLane Modelほど説明が整っていません。
